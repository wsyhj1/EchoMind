# 第三阶段启用、观测与回滚

## 当前状态

第三阶段交付时，代码已接入实际检索工具且默认关闭，当时未改动用户配置或真实图谱。2026-10-23 按用户授权完成独立代理审核和受控真实库启用，当前用户图谱已开启；证据检查仍关闭。历史实验记录保留，最新运行状态见 [第四阶段记录](04_activation_report.md)。

阶段一/二正式效果 Gate 的人工审核仍待完成。当前规则覆盖范围和合成实验不能证明生产问题的答案准确率，保持实验选项，按受控范围验证后再考虑推广。

## 启用

更新后端并重启服务，然后在「设置 → RAG 设置」将「证据完整性检查（实验）」设为开启并保存。新提问开始生效，不修改已有历史回答。此选项可独立于图谱启用，原 Top K 与重排选择继续有效。

也可在服务端配置 `EVIDENCE_CHECK_ENABLED=true`，作为选择「跟随服务默认」用户的默认值，重启后端生效。服务端默认不覆盖用户明确保存的开启/关闭值。

先验证：简单问题不补检、复合问题只补一次、补检不越过当前库、无答案时明确缺乏依据、冲突时保留两方来源。关注 `evidence`、`evidence_check`、`evidence_retrieval`、`evidence_rerank` 的耗时与 fallback；高超时率先减少实验并发或保持关闭，不通过无限加预算掩盖失败。

## 回滚

单用户立即回滚：在 RAG 设置中将证据检查设为「关闭」，保存；从下一题回到首轮检索。若也要回到 A 组，图谱辅助召回同时设为「关闭」。重排、检索方式与 K 维持对照参数。

服务默认回滚：将 `EVIDENCE_CHECK_ENABLED=false`，必要时也将 `GRAPH_RAG_ENABLED=false`，重启后端。**这只改变跟随默认的用户；已经显式开启的用户仍须通过用户设置关闭。** 禁止声称单改默认开关已强制关闭所有用户。

可通过 `GET /user-settings?user_id=...` 读取当前值与 revision，再以完整 `values`、`expected_revision` 调 `PUT /user-settings`，把 `evidence_enabled`/`graph_enabled` 设为 false。保留其他字段，409 时刷新核对后重试。不要直接批量覆写 JSON 而丢掉用户记忆/检索偏好。

证据检查没有独立存储表，不需要删除图谱或做数据库回滚。禁用之后无需更改 Milvus 集合、父块或长期记忆。保留实验原始结果、失败日志和代码指纹供复查。
