## 执行边界

每条计分引文均能在源文本中按 `start_char/end_char` 精确定位，并记录独立 `source_span_id` 和原文hash；权限也逐条复核。BH001两段位于同一长文的开头和末尾，不能用整个doc_id命中宣称完整证据，也不能假设它们落在同一父块。

现有按doc_id映射单父块的实验适配器不足以直接验证该长文集；必须建立跨度到真实切块的映射。两个多轮题要求runner真实提供历史，冲突题要求两个来源及其时间/替代限定，单凭图谱边命中不代表数值或冲突回答正确。

本交付完成Gold源审核与可审计新版本，没有执行32题实际召回或回答，因此不报告命中率、答案准确率或上线效果，也不把代理审核伪装为真人验收。后续执行应使用独立测试schema/集合/身份，保留留出集边界，避免用Gold调业务规则后再称其为未见测试集。
