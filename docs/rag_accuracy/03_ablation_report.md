## 最终边界防护的一致性复核

云实验结束后，额外收紧了未被本批短父块触发的边界：超长上下文丢弃整块而不截断流程；同一父块多种故障时不猜测步骤归属；更多显式时态提示保持不确定；步骤句子须完整结束。
真实 Agent 的覆盖目标改为读取请求 trace 中的原始用户问题，避免工具改写漏掉时间、版本或子问题；直接检索实验的原始/工具查询本来相同。
审计覆盖 16 个全部实测父块，规则输出全部一致；198 道 C/D 题的最终覆盖与新规则一致，且所有实测上下文均低于预算。
这是最终源码的离线一致性验证，不冒充第二轮云模型实测。对应边界另有失败后通过的回归测试。
