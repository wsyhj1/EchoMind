# 作品报告领域图谱适配与边界

2026-10-24领域模块开发；2026-10-25主代理追加真实报告验证。子代理最初的模块验证未调用真实文件模型；后续真实运行及限制见 [本轮验收](06_improvements_acceptance.md)。合成留出集的本地校验不作为业务准确率。

## 本体和迁移

保留原System、Service、Product等类型，新增Feature、Module、Model、Dataset、Experiment、Metric、Report。数据集、案例集合和指标不得为了满足旧类型而伪装成Service或Database。Metric表示指标名称；具体分数、单位、样本量、时间和实验条件保留在原文中，图边不承担数值推理。

| 关系 | 方向与允许范围 | 明确句式例子 |
|---|---|---|
| HAS_FEATURE | 产品/系统/服务 → 功能 | 产品甲具有功能乙。 |
| HAS_MODULE | 产品/系统/服务 → 模块 | 产品甲包含模块丙。 |
| IMPLEMENTED_BY | 功能 → 模块/模型/服务 | 功能乙由模块丙实现。 |
| EVALUATED_ON | 组件/功能/模型/实验等 → 数据集 | 模块丙在数据集丁上评估。 |
| REPORTS_METRIC | 实验/报告/组件等 → 指标名称 | 实验戊报告宏平均指标己。 |
| HAS_EXPERIMENT | 产品/系统/模块/报告 → 实验 | 产品甲开展实验戊。 |

Module可使用Model或其他Module；Module可属于System/Product。旧7种谓词继续有效。原003迁移只有predicate存在CHECK，entity_type一直是varchar。006独立扩展predicate CHECK，未修改已经应用的003；迁移执行、校验和及幂等由GraphRepository统一处理。

## 保守语义和召回

新增关系在抽取验证和在线读取时均检查：端点属于允许类型，端点和别名出现在引用中，引用真实包含明确的关系方向。不认可仅共同出现、参考文献、页面顺序、独立开发、假设、否定、计划和不确定表达。表格单元格并列不自动变成关系；未知句式留下文本检索回退。

在线查询继续最多两跳，支持产品→功能→实现模块、产品→模块→评估数据、产品→实验→指标名称。具体数值、置信区间、跨年/跨版本、冲突与比较问题不使用这些当前关系模板，转回原文本证据流程。这里只选择是否增加图证据，并不改变文本检索对原始资料的可见性，也不把空图结果当作“资料没有答案”。

此图谱不自动拼接不同章节的半句话，不推测表格表头或继承全篇历史时态，不解决指代、不强行消解歧义别名、不选择冲突记录的胜者。单份长引用中包含未来或历史等限制时宁可不建边。没有显式适配句式的领域关系必须保持未知。

## v3写入和v2兼容读取

新默认抽取版本为v3，默认可读顺序为v3、v2；显式version=v2只读取v2。READY以外的作业不提供在线边。

优先级按每个不可变源文件的user_id、knowledge_base_id、file_hash分别计算：同文件v3 READY后，旧v2的实体提及和所有边证据均失去在线资格，即使v3删除了原来的某条边。v3处于PENDING、FAILED等非READY状态时，仍可回退该文件READY的v2。不同文件可分别使用各自最高READY版本。每份在线引用仍须匹配当前parent原文和文件身份，不因为兼容版本而放松租户或库隔离。

版本切换不会自动重新入队或抽取真实文件。需要用户通过有范围、有预算的管理任务明确触发重新索引。旧v2数据保留供审计和显式回退。

## 请求预算接入

GraphExtractor保留原settings/client调用方式，新增可选async before_request钩子。每次真正发送模型请求前调用一次，包括格式校验后的重试。钩子在模型重试捕获之外，预算耗尽、失去租约或用户取消不会被误判为模型错误再发一次请求。管理作业由独立管理模块承担预算预留和取消状态；本模块不自行修改作业或消费真实预算。

## 验证范围

通用句法单元测试使用产品甲、模块丙等例子，不读业务留出题或Gold答案。首轮本地/mock图谱测试27项通过，15项PostgreSQL用例在不配置隔离测试地址时明确跳过；新增领域与预算钩子测试8项。独立留出集完整性3项通过。

随后实际配置本地隔离PostgreSQL地址，使用每用例独立随机schema运行12项数据库测试，全部通过并清理schema。其中包括2项新增报告领域测试、9项原repository测试和1项原错误边绕过测试；不是将跳过计为通过。已验证006新谓词落库、默认v3读取旧v2、PENDING v3回退、同文件v3 READY删边遮蔽旧v2、另一文件v2不受影响、显式v2固定读取、迁移幂等、租户/库边界与当前原文失效。没有读取或重抽真实用户报告。

本变更不构成真实作品报告上的召回、回答准确率或引用质量结论。独立候选集及待执行条件见05_business_holdout.md；旧基线、phase4清单与结果未修改。

2026-10-25主代理实际验收补充：同句完整列表的“系统由A、B组成”可形成HAS_MODULE；案例/数据集不可伪装Module，子串与省略名称不补全。System的“当前/目前”可作为有限查询前缀处理，但不改源实体身份；共享别名、同stem碰撞和候选截断不会被当作唯一实体。DOCX最终3条可用关系，PDF尚无可用v3关系；真实问题及验证边界详见06_improvements_acceptance.md，不以此代替32题业务留出效果评测。
