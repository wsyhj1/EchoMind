# EchoMind 设置

打开侧边栏「新对话」右侧的齿轮按钮。面板左侧切换分类，窄屏时分类移到上方。侧栏「回答配置」展示已保存的检索方式、Top K、重排、图谱和画像状态，点击检索或画像摘要即可跳转到相应分类。完整的画像编辑与开关集中在设置中。

侧栏优先显示知识库与本库文档，「添加文档」默认折叠，点击后展开上传区。

## 可配置内容

| 分类 | 选项 | 生效方式 |
| --- | --- | --- |
| RAG 设置 | 混合检索 / 语义检索、Top K（1–20）、结果重排、图谱辅助召回、证据完整性检查（实验） | 点击「保存 RAG 设置」，从下一次提问起生效 |
| 画像设置 | 手动背景、目标、兴趣、回答偏好；画像使用开关、自动更新开关；查看自动摘要、清空画像 | 手动字段点击「保存画像」；开关即时保存；清空需要勾选确认 |
| 对话与记忆 | 使用长期记忆与画像 | 点击「保存记忆设置」，从下一次提问起生效 |
| 模型与服务 | 查看当前对话、向量、重排模型 | 只读；连接信息与密钥继续由服务端管理 |

配置保存在 PostgreSQL，属于当前用户，适用于该用户的全部知识库。刷新页面、开始新对话、重新启动服务后仍有效。恢复 RAG 默认值只恢复 RAG 部分，不改变记忆或画像。

默认值为：混合检索、Top K = 5、开启重排、图谱跟随服务默认、启用长期记忆与画像。画像仍受独立的「使用画像回答」开关控制。

证据检查默认跟随服务的关闭值，可独立开启；首版保守检查中文运维与实例关系问题，缺少可识别证据时最多补检一次。检查本身不调用模型，补检可能增加 embedding 和重排调用，仍受原 Top K 与上下文预算限制。详见 [证据检查说明](rag_accuracy/03_evidence_check.md)。

关闭「使用长期记忆与画像」会在新回答中禁用长期记忆工具与画像注入；当前会话上下文、对话保存与后台整理仍保留。画像摘要的后台更新由画像分类中的独立开关控制。

个人工作台中的项目任务、决定和进展属于显式保存的项目业务状态，与通用长期记忆开关分开。项目会话会读取绑定项目的状态；普通会话不会因此自动关联项目。项目助手的工作方式见[学习说明](personal-assistant-learning.md)。

## 图谱召回

图谱选项支持「跟随服务默认 / 开启 / 关闭」。跟随默认时读取 `GRAPH_RAG_ENABLED`；用户明确选择后，该用户的在线召回使用所选值。

开启在线召回需要已有图谱索引。此开关不会构建或重建索引，也不会启用上传时的后台抽取；后台抽取仍由服务端 `GRAPH_EXTRACTION_ENABLED` 管理。缺少索引、图谱不可用或超时时，检索服务回退到常规检索。索引的构建与回填见 [图谱回填说明](rag_accuracy/02_graph_reindex.md)。

2026-10-23 已在用户授权的本地范围完成3份文档、136父块回填，并为当前用户显式开启图谱召回（保存版本v2）。线上语义守卫拒绝没有明确方向支持的关系；新文档自动抽取仍关闭。实际状态、代理审核、限制和回滚见 [启用记录](rag_accuracy/04_activation_report.md)。

## API 与升级

服务启动时自动执行幂等迁移 `backend/migrations/004_user_settings.sql`，在 `users` 中新增独立的配置、版本和更新时间字段，保留原画像及其版本。

- `GET /user-settings?user_id=1`：返回 `values`、`revision`、`updated_at`、`defaults` 和公开模型信息 `runtime`。
- `PUT /user-settings?user_id=1`：提交完整 `values` 和 `expected_revision`。版本冲突返回 409；不存在的用户返回 404；非法字段和越界参数返回 422。
- `/chat_with_agent/stream`：省略的检索与记忆参数使用已保存配置；显式请求参数覆盖用户默认值。每轮评测快照记录实际参数及设置版本。
- `evaluation_mode=true`：不继承个人设置，保持评测默认参数；显式评测参数仍可覆盖，记忆和画像保持关闭。

多页面同时编辑时，旧页面不能覆盖新配置。RAG 与记忆保存失败会保留当前草稿；冲突时使用「重新加载已保存设置」读取最新配置后再修改。画像编辑沿用独立的版本检查与草稿保护。

## 验证

新增设置测试不调用模型。后端使用独立 PostgreSQL schema 验证持久化、用户隔离、并发冲突、API 校验、请求覆盖、评测隔离和检索工具参数传递；前端 AppTest 验证保存、恢复默认、失败重试、分类导航与新会话加载。真实浏览器另外检查弹窗关闭重开、桌面与 390px 窄屏布局。

2026-10-22 验证：76 项后端回归、18 项前端测试全部通过；真实浏览器四分类导航、关闭重开及 390px 布局通过，验证前后真实用户的配置和画像保持一致。
