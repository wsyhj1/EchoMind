# EchoMind 创新路线：相关工作与证据边界

核对日期：2026-10-27。以下为一手资料核对与设计建议，不是 EchoMind 已完成的实验结论。

## 已有方法与项目机会

| 一手来源 | 已有工作 | 对 EchoMind 的启示与边界 |
| --- | --- | --- |
| [Self-RAG 论文](https://arxiv.org/abs/2310.11511) | 训练模型使用反思 token，按需检索并评价证据及生成。 | 可借鉴“检索—核验—修正”的闭环；使用现成模型加提示词不等于复现其训练方法，闭环本身也不能称为原创。 |
| [CRAG 论文](https://arxiv.org/abs/2401.15884) | 检索评估器根据质量触发不同检索动作，并结合网络搜索和证据分解重组。 | 可针对私有报告做有预算的重检索、查询分解和拒答；不必为了追随论文默认联网。评价器可能误判，应单独计量。 |
| [Microsoft GraphRAG 官方查询说明](https://microsoft.github.io/graphrag/query/overview/) | Local Search 组合图谱和原文；Global Search 通过社区报告进行 map-reduce；同时提供基础向量检索。 | “图谱+向量”已有成熟先例。更值得验证的是按问题选择文本或图谱、图谱证据不足时回退；不能由存在图谱推断回答更好。 |
| [LongMemEval 作者仓库](https://github.com/xiaowu0162/LongMemEval) | 原始基准含500题，评信息提取、跨会话推理、知识更新、时间推理和拒答。 | 为记忆专项评测提供分类。固定数据版本、回答模型、裁判和上下文预算；中文项目样本与原基准分别报告，不能混作官方成绩。 |
| [Graphiti 官方仓库](https://github.com/getzep/graphiti) | 保存事实有效期、过时事实的历史及来源，支持时间图谱和混合检索。 | 时间记忆与冲突更新不是空白领域。项目可研究“人工确认事实优先、原文可追溯、过期或删除信息不再进入回答”的完整行为。其产品性能描述不能直接迁移为本项目指标。 |

## 建议形成的主线

“面向持续变化的项目资料，构建有来源、有时间、可纠错且有成本边界的个性化问答系统。”这是适合当前项目的工程研究定位；是否构成学术方法创新，仍需更完整文献检索与对照实验。

1. **证据驱动的回答闭环**：将回答拆成可检查的事实声明，区分原文支持、矛盾、缺证；缺证时最多再检索一次，仍不足则保留不确定性。引用位置有效与语义支持分开计分。
2. **可修正的时间记忆**：原子事实保留来源消息、有效期和替代关系；“过去偏好”和“当前偏好”可分别查询。将用户明确修正、文档事实和模型推断分开，避免记忆反复污染。
3. **按问题与预算选证据**：事实定位优先文本，关系问题尝试图谱，跨版本问题使用时间过滤；只有收益可测时才增加路径和调用。

## 能证明个人贡献的实验

固定生成模型、语料快照与预算，比较基础 hybrid RAG、加核验、加时间记忆、完整系统，并逐项移除模块。单列关系、跨版本、无答案与记忆更新题；同时报告答案正确性、声明证据支持率、错误沿用率、拒答精确率/召回率、p95延迟和成本。冻结留出集，展示逐题失败案例和重复运行波动；不把单个成功演示或裁判分数解释为通用提升。
